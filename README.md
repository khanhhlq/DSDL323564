# 🚀 DSDL323564 - Thực tập Thiết kế và Tổng hợp Hệ thống Số

Repository này lưu trữ mã nguồn, mô phỏng và các bài thực hành của môn học **Thực tập Thiết kế và Tổng hợp Hệ thống Số**.

## 📌 Thông tin học phần
- **Mã môn học:** DSDL323564
- **Lớp học phần:** 24161TKVM1B
- **Giảng viên hướng dẫn:** Nguyễn Văn Thành Lộc
- **Phòng học:** C401A
- **Trường:** HCMUTE

## 🧩 Tổng quan dự án
Repository được tổ chức theo từng buổi thực hành (Session) và các bài kiểm tra giữa kỳ / cuối kỳ, tập trung vào các chủ đề:
- Mạch logic tổ hợp cơ bản
- Đồng hồ và bộ đếm
- Điều khiển LED theo trạng thái / tốc độ
- Thiết kế hệ thống số theo yêu cầu thực tế
- Mô phỏng và kiểm chứng bằng HDL
